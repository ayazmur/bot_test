Сделать приложение, которое может уведомлять пользователей о предстоящих событиях в календаре Outlook.
Минимальные требования:
1) Возможность уведомлять пользователя о каком-либо событии (задается по его названию) - способ связи не важен, можно сделать отдельное сообщение на почту, в ТГ и тд
2) Приложение должно добавлять в календарь пользователя Outlook событие на основе его текущих встреч
3) Приложение должно работать на микро-сервисной архитектуре. Отдельным микросервисом задается моковый сервис outlook, в котором реализована JSON-БД
